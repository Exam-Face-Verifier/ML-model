# Face Verification system #

This is the backend code for our 'Exam Face Verifier' application. It links the app to the database and performs the matching algorithm. To connect to the mobile app you must be on the same network. 

## Instructions ##

Pull the image from docker hub and run it through:

```
docker pull likithps12/fv

docker run -it likithps12/fv
```

Scan the qr code throught the Exam-face Verifier app and your setup will be complete.
